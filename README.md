# Sistema de control de empleados
Simulando una base de datos que guarda, en un solo archivo txt, los datos de los empleados.

Al dar de alta a un empleado, se pide:
-ID (Se autogenera)
-Nombre
-Apellido Paterno
-Apellido Materno
-Fecha de Nacimiento
-Direccion
-Fecha de Alta (Se genera automaticamente con la hora local)

El sistema tiene como opciones:

-Alta
-Baja
-Consulta
-Modificación
-Salir

La consulta se puede realizar por nombre, o ID o consultar todos los empleados
La baja de empleados se puede hacer por ID o por nombre del empleado
